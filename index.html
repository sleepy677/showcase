01 几何构成 p5.js · 静态作品
说明

网格上圆与方块交替排布，颜色随坐标连续过渡的静态构成画面。

创作思路

以网格为骨架，用 map() 把坐标映射成 RGB 值，让颜色随位置连续渐变；再按 (x+y) 的奇偶交替画圆和方块，形成节奏感，图形尺寸也随坐标缓慢缩放。

技术 p5.js · Canvas 2D · map() 渐变映射

02 运动轨迹 p5.js · 交互作品
说明

鼠标划过海面激起涟漪，一圈圈扩散、变淡、消失。

创作思路

海面用逐行插值画渐变；鼠标划过时在指针处生成波纹，半径扩散、透明度衰减，越界即回收。双层椭圆叠出水面透视，再加一层缓慢漂移的细波纹，静止时海面也不死板。

技术 p5.js · Canvas 2D · 数组管理粒子生命周期

03 躲避游戏 3D Three.js · 小游戏
说明

3D 场地里用 WASD 移动，躲开四面飞来的能量球，撑过 180 秒。

创作思路

把 2D 躲避玩法搬进三维：发光网格场地配指数雾营造空间感，能量球从场地外圈随机生成、朝玩家直线飞来；碰撞用 XZ 平面距离判定，命中后清场并进入短暂无敌闪烁。

技术 Three.js (r128) · WebGL · 透视相机 · 实时阴影
