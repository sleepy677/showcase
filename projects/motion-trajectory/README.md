# 运动轨迹

一片通透的海面，鼠标划过时激起一圈圈扩散的椭圆涟漪，随透明度衰减而消散。

- **作者**：朱栩汕
- **技术**：p5.js（canvas 2D，交互 · 动画）
- **在线预览**：https://sleepy677.github.io/showcase/projects/motion-trajectory/
- **操作**：移动鼠标或按住拖动，在水面上激起涟漪
- **演示视频**：[demo.mp4](demo.mp4)

## 实现思路

画面由三部分构成：

1. **海面渐变**：逐行绘制 1px 矩形，用 `lerp()` 把纵向坐标插值成从深海蓝 `(30, 90, 150)` 到浅青 `(70, 160, 200)` 的渐变。
2. **波纹生成**：检测鼠标位移（`mouseX - pmouseX > 2`）或按压时，在指针位置推入一个波纹对象，初始半径、最大半径、扩散速度由 `random()` 随机生成。
3. **波纹演化**：每帧半径递增、透明度递减，用 `if` 判断超出最大半径或透明耗尽即从数组移除；每个波纹绘制两层同心椭圆，形成透视感更强的水面涟漪。另有一层缓慢横移的细波纹，让静止时海面也不死板。
